# Feedback Guide

아래 질문에 짧게 답해주시면 됩니다.

## 첫 실행

- `LUMOS.exe` 실행이 쉬웠나요?
- Companion이 어떤 역할을 하는지 이해됐나요?
- 브라우저에서 Web UI가 자연스럽게 열렸나요?
- 보안 경고나 실행 차단이 있었나요?

## 오늘의 신호

- 오늘의 신호가 무엇인지 바로 이해됐나요?
- 3개라는 개수가 적절했나요?
- 한국어 briefing이 자연스러웠나요?
- 영어 원문 자료를 부담 없이 이해할 수 있었나요?
- 가장 유용했던 신호는 무엇이었나요?

## 행동 버튼

- 저장 / 관심 없음 / 계속 추적의 차이가 명확했나요?
- 원문 보기 버튼의 의미가 명확했나요?
- feedback을 누른 뒤 앱이 어떻게 반응하는지 이해됐나요?

## 가격

- 월 9,900원 Pro에 관심이 있나요?
- 관심이 있다면 어떤 기능이 반드시 필요할까요?
- 관심이 없다면 어떤 점이 부족했나요?

## 개인정보

- local-first 설명이 충분히 신뢰됐나요?
- 어떤 데이터 사용이 가장 걱정됐나요?
- 삭제 방법이나 데이터 위치 안내가 충분했나요?
