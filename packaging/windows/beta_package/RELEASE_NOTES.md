# LUMOS 0.1.0-alpha Release Notes

Release channel: closed beta prototype

## 포함된 기능

- LUMOS Companion 실행
- 브라우저 기반 `/app` Web UI
- First-run onboarding
- 오늘의 신호 생성
- 영어 원문 기반 자료의 한국어 briefing card
- 저장 / 관심 없음 / 계속 추적 feedback
- 로컬 모드 사용
- 계정/요금제 shell과 개발용 cloud 연결 확인 영역

## 포함되지 않은 기능

- 정식 installer
- code signing
- auto-update
- OS startup 또는 tray 실행
- 실제 회원가입
- 실제 결제
- production cloud login
- 일반 공개 다운로드

## 안내

이 build는 closed beta prototype입니다. 일반 공개 배포용이 아니며, 선정된 beta tester에게만 수동 전달하는 것을 전제로 합니다.
