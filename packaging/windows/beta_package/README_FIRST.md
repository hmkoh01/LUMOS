# LUMOS Beta 시작하기

LUMOS는 매일 쏟아지는 정보 중에서 오늘 봐야 할 신호만 골라 한국어 브리핑으로 보여주는 local-first 베타 앱입니다.

## 실행 방법

1. zip 파일을 원하는 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 `LUMOS.exe`를 실행합니다.
3. 기본 브라우저에서 LUMOS Web UI가 열립니다.
4. 처음 실행하는 경우 `시작하기`를 눌러 온보딩을 진행합니다.

브라우저가 자동으로 열리지 않으면 아래 주소를 직접 입력하세요.

```text
http://127.0.0.1:8000/app
```

오늘의 소식 읽기, 온보딩, 설정 확인은 브라우저 화면에서 진행합니다.

## 종료 방법

브라우저 탭을 닫고 실행 중인 LUMOS 프로세스를 종료하면 됩니다.

## 데이터 위치와 삭제

Portable beta는 실행 폴더 옆의 `data/` 폴더에 로컬 데이터를 저장합니다.

- 앱만 삭제하려면 압축을 푼 LUMOS 폴더를 삭제합니다.
- 로컬 데이터까지 삭제하려면 같은 폴더 안의 `data/` 폴더도 삭제합니다.
- `data/`를 삭제하면 온보딩, 오늘의 신호, 피드백 기록이 초기화됩니다.

## 보안 경고가 보일 때

현재 alpha portable build는 code signing 전 단계입니다. Windows SmartScreen 또는 antivirus 경고가 보일 수 있습니다.

신뢰할 수 있는 beta 전달 경로로 받은 파일만 실행하세요. 의심스러우면 실행하지 말고 전달자에게 문의하세요.

## 문제 제보

실행 단계, 화면 문구, 오류가 발생한 시점을 간단히 적어 보내주세요.

브라우저 방문 기록, 로컬 파일 원문, 개인 문서 내용은 보내지 마세요.
