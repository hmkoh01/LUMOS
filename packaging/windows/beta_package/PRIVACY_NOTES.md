# Privacy Notes

LUMOS beta는 local-first 원칙을 기준으로 동작합니다.

## 로컬에 저장되는 데이터

Portable beta는 실행 폴더 옆의 `data/` 폴더를 사용합니다.

저장될 수 있는 데이터:

- 온보딩 설정
- 관심 키워드
- 오늘의 신호 cache
- 저장, 관심 없음, 계속 추적 같은 feedback 기록
- 사용자가 명시적으로 켠 connector 기반 요약 정보

## 기본 원칙

- 브라우저 기록 전체나 로컬 파일 원문 전체를 기본적으로 서버로 보내지 않습니다.
- 개인 맥락 connector는 사용자가 켠 경우에만 사용합니다.
- Cloud 연결 기능은 개발 확인용이며 closed beta 사용에 필수 기능이 아닙니다.
- Web UI에는 token 값이 표시되지 않습니다.

## 데이터 삭제

앱만 삭제하려면 압축을 푼 LUMOS 폴더를 삭제합니다.

로컬 데이터까지 지우려면 실행 폴더 안의 `data/` 폴더도 삭제하세요. `data/`를 삭제하면 온보딩, 오늘의 신호, feedback 기록이 초기화됩니다.

## 제보 시 주의

오류를 제보할 때 브라우저 방문 기록, 로컬 파일 원문, 개인 문서 내용, 민감한 URL은 보내지 마세요.
