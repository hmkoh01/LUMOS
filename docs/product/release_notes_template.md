## Setup Steps

1. 안내받은 압축 파일을 풉니다.
2. `LUMOS.exe` 또는 지정된 실행 파일을 실행합니다.
3. 브라우저에서 `/app`이 열리는지 확인합니다.
4. 시작하기를 눌러 관심사와 역할을 설정합니다.
5. 오늘의 신호를 받아봅니다.

## Privacy Note

LUMOS는 local-first 방향을 원칙으로 합니다. 브라우저 기록과 로컬 파일 원문은 기본적으로 서버로 보내지 않는 방향으로 설계하고 있으며, connector는 사용자가 켠 경우에만 사용합니다.
