# Closed Beta Intake Plan

## 목적

Closed beta는 LUMOS가 실제 사용자의 daily briefing 문제를 해결하는지 확인하기 위한 수동 모집 단계다. 목표는 기능을 많이 보여주는 것이 아니라, 사용자가 매일 봐야 할 신호를 줄여주는 가치가 있는지 검증하는 것이다.

확인할 핵심 가설:

- 사용자는 정보가 부족해서가 아니라 고르는 시간이 커서 피로하다.
- 영어 원문 기반 자료를 한국어 briefing으로 정리하면 실제로 읽을 가능성이 높아진다.
- 예비 창업자, PM, 1인 창업자는 매일 3개의 선별된 신호에 가치를 느낄 수 있다.
- 월 9,900원 Pro 가격은 특정 high-fit 사용자에게 검증할 만한 가설이다.
- local-first 개인정보 메시지는 설치형 앱 사용의 불안을 낮춘다.

## 우선 모집 대상

1. 예비 창업자
2. 1인 창업자
3. PM / Product Builder
4. AI/생산성 툴을 자주 보는 지식근로자
5. 스타트업/기술 트렌드를 계속 추적해야 하는 사람

## 신청 질문

필수 질문:

- 어떤 일을 하고 있나요?
- 매일 어떤 정보를 확인하나요?
- 현재 트렌드를 따라가기 위해 쓰는 도구는 무엇인가요?
- 하루에 정보 탐색에 쓰는 시간은 어느 정도인가요?
- 어떤 주제의 신호가 가장 필요하나요?
- 영어 원문을 한국어로 요약해주는 기능이 필요한가요?
- 개인 맥락 기반 추천에 관심이 있나요?
- 월 9,900원 Pro에 관심이 있나요?
- Windows 사용자인가요?
- 설치형 로컬 앱 사용에 거부감이 있나요?
- 베타 피드백 인터뷰에 응할 수 있나요?

## 선별 기준

High-fit 신호:

- 매일 트렌드, AI, product 정보를 확인한다.
- 정보 탐색 시간이 부담이라고 말한다.
- 영어 원문을 읽고 선별하는 데 피로가 있다.
- 창업, 제품, 리서치 맥락이 분명하다.
- Windows 환경에서 테스트할 수 있다.
- 15분 피드백 인터뷰에 응할 의향이 있다.

Low-fit 신호:

- 트렌드 추적 니즈가 약하다.
- 모바일 앱만 원한다.
- 설치형 앱에 거부감이 크다.
- 가격 지불 의향이 전혀 없다.
- local-first 설명 후에도 개인정보 불안이 크다.

## Cohort 운영

1차 cohort: 3~5명

- 목적: 설치/첫 실행 friction 확인
- 기간: 3~5일
- 성공 기준: 80% 이상 첫 오늘의 신호 수신 성공

2차 cohort: 10명

- 목적: briefing 품질과 반복 사용 의향 확인
- 기간: 1주
- 성공 기준: 절반 이상이 3회 이상 실행

3차 cohort: 30명

- 목적: 가격 가설과 주요 persona 검증
- 기간: 2주
- 성공 기준: Pro 관심 있음 응답 20% 이상

## 운영 방식

- 신청은 `/beta`의 질문 템플릿을 복사해 이메일로 보내는 수동 방식이다.
- 외부 form SaaS나 이메일 수집 backend는 아직 사용하지 않는다.
- 선정자는 participant id로 관리하고, 민감한 개인정보는 별도로 저장하지 않는다.
- 배포 전 `docs/product/download_readiness_checklist.md`를 통과해야 한다.
