# Landing Copy

Date: 2026-07-06

## Hero Copy Candidates

1. 매일 쏟아지는 정보 속에서 오늘 봐야 할 3개의 신호만 받아보세요.
2. 더 많은 뉴스가 아니라, 오늘 판단에 필요한 신호만.
3. 검색하기 전에 도착하는 개인화 트렌드 브리핑.

## One-Liner Candidates

1. LUMOS는 오늘 봐야 할 신호만 한국어로 정리하는 개인 브리핑 앱입니다.
2. 영어 원문 흐름을 내 관심사에 맞춘 한국어 briefing card로 바꿉니다.
3. 뉴스레터처럼 모두에게 같은 정보가 아니라, 내 맥락에 맞는 신호를 고릅니다.
4. 검색하지 않아도 중요한 변화가 먼저 도착하는 경험을 목표로 합니다.
5. 더 많이 읽게 하는 앱이 아니라 덜 헤매게 하는 앱입니다.

## Problem Copy

정보가 부족한 것이 아니라 너무 많습니다. 매일 뉴스레터, 커뮤니티,
GitHub, 공식 블로그를 확인하다 보면 중요한 변화보다 선별 시간이 먼저
커집니다.

## Solution Copy

LUMOS는 역할, 관심사, 작업 맥락을 기준으로 source를 확인하고, 중요한
후보를 ranking한 뒤 한국어 briefing card로 정리합니다. 저장, 관심 없음,
계속 추적 feedback은 다음 추천에 반영됩니다.

## Privacy Copy

개인 맥락은 로컬 우선으로 다룹니다. 브라우저 기록과 로컬 파일 원문은
기본적으로 서버로 보내지 않는 방향을 원칙으로 하며, connector는 사용자가
켠 경우에만 사용합니다.

## Pricing Copy

Free는 기본 신호를 확인하는 시작점입니다. Pro는 더 많은 신호, 자동 브리핑,
고급 source, 개인 맥락 connector 확장을 검토하는 유료 가설입니다. Pro
가격은 월 9,900원으로 검증 중입니다.

## FAQ Copy

### ChatGPT와 무엇이 다른가요?

ChatGPT는 내가 물어봐야 작동합니다. LUMOS는 오늘 봐야 할 신호가 먼저
도착하는 경험을 목표로 합니다.

### Perplexity와 무엇이 다른가요?

Perplexity는 질문에 대한 답을 찾는 데 강합니다. LUMOS는 사용자의 관심사와
반복 feedback을 바탕으로 매일 볼 변화를 줄이는 데 집중합니다.

### 뉴스레터와 무엇이 다른가요?

뉴스레터는 모두에게 같은 내용을 보냅니다. LUMOS는 역할, 관심사, 작업 맥락,
feedback을 기준으로 더 개인화된 briefing을 목표로 합니다.

### RSS reader와 무엇이 다른가요?

RSS reader는 source를 모아 보여줍니다. LUMOS는 source 후보 중 오늘 볼
신호를 줄이고, 왜 중요한지와 다음 행동을 설명합니다.

## Positioning Rules

Avoid:

- AI가 알아서 다 해줍니다.
- 모든 정보를 실시간으로 추적합니다.
- 완벽한 자동화입니다.
- 이미 상용 결제가 가능합니다.

Prefer:

- 오늘 봐야 할 신호를 줄입니다.
- 영어 원문도 한국어 briefing으로 이해하기 쉽게 보여줍니다.
- 개인 데이터는 로컬 우선으로 다룹니다.
- 현재는 베타와 가격 검증 단계입니다.
