# Beta Email Templates

아래 템플릿은 closed beta 수동 운영용이다. 아직 자동 이메일 발송 backend는 없다.

## A. 신청 접수 확인

제목: LUMOS closed beta 신청을 받았습니다

안녕하세요.

LUMOS closed beta에 관심을 보내주셔서 감사합니다. 현재는 소규모 cohort로 수동 선별 중이며, 사용 환경과 관심 주제가 이번 테스트와 맞는 분께 개별 연락드릴 예정입니다.

LUMOS는 아직 closed beta 준비 단계입니다. 정식 회원가입, 결제, 일반 공개 다운로드는 제공하지 않습니다.

감사합니다.

## B. Cohort 1 선정 및 다운로드 안내

제목: LUMOS closed beta Cohort 1 참여 안내

안녕하세요.

LUMOS closed beta Cohort 1에 초대드립니다. 이번 빌드는 Windows portable alpha build이며, 선정된 beta tester에게만 수동으로 전달합니다.

전달 artifact:

- 파일명: `LUMOS-0.1.0-alpha-portable.zip`
- SHA256: `2074F5780806D71703D6A5D581A5708B10A41A1C1479EF60C021D143621084C5`
- 버전: `0.1.0-alpha`

실행 방법:

1. zip 파일을 원하는 폴더에 압축 해제합니다.
2. 압축을 푼 폴더에서 `LUMOS.exe`를 실행합니다.
3. 작은 `LUMOS Companion` 창이 열리면 `오늘의 신호 열기`를 누릅니다.
4. 브라우저에서 `시작하기`를 눌러 온보딩을 진행합니다.
5. 오늘의 신호 3개를 확인하고, 저장 / 관심 없음 / 계속 추적 중 하나를 눌러봅니다.

주의:

- 현재 build는 code signing 전 단계라 Windows SmartScreen 또는 antivirus 경고가 보일 수 있습니다.
- 신뢰할 수 있는 전달 경로로 받은 파일만 실행하세요.
- 의심스럽거나 실행이 불안하면 실행하지 말고 바로 문의해 주세요.
- 브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8000/app`을 직접 입력해 주세요.

피드백은 첫 실행 후 10분 안에 느낀 점을 짧게 보내주시면 됩니다. 특히 첫 실행이 쉬웠는지, 오늘의 신호가 이해됐는지, 월 9,900원 Pro 가격이 설득력 있는지 알고 싶습니다.

감사합니다.

## B-0. Canary tester 첫 실행 요청

제목: [LUMOS Canary] 첫 실행 테스트 부탁드립니다

안녕하세요.

LUMOS closed beta를 3~5명에게 보내기 전에, 신뢰 가능한 canary tester 1명에게 먼저 실행 가능 여부를 확인하고 있습니다. 아직 일반 공개 제품이 아니며, 이번 테스트는 closed beta 전 단계의 Windows portable alpha build 확인입니다.

전달 artifact:

- 파일명: `LUMOS-0.1.0-alpha-portable.zip`
- SHA256: `2074F5780806D71703D6A5D581A5708B10A41A1C1479EF60C021D143621084C5`
- 다운로드 링크: `[수동 전달 링크 또는 첨부 위치를 여기에 입력]`

중요 안내:

- 현재 build는 code signing 전 단계라 Windows SmartScreen, Windows Defender, antivirus, firewall 경고가 보일 수 있습니다.
- 보안 경고가 의심스럽거나 실행이 불안하면 실행하지 말고 바로 알려주세요.
- 신뢰할 수 있는 전달 경로로 받은 파일만 실행해 주세요.
- 이 테스트는 약 10~15분 정도 걸립니다.

실행 순서:

1. zip 파일을 새 폴더에 압축 해제합니다.
2. `LUMOS.exe`를 실행합니다.
3. SmartScreen/Defender/firewall 경고가 보이면 캡처하고, 실행이 불안하면 중단합니다.
4. `LUMOS Companion` 창이 보이는지 확인합니다.
5. 브라우저가 자동으로 열리는지 확인합니다.
6. 브라우저가 열리지 않으면 `http://127.0.0.1:8000/app`을 직접 입력합니다.
7. `시작하기`를 눌러 onboarding을 진행합니다.
8. 오늘의 신호 3개를 생성합니다.
9. signal card에서 details를 열어보고, 저장 / 관심 없음 / 계속 추적 중 하나를 클릭합니다.
10. 앱을 닫고 다시 실행해 이전 상태가 유지되는지 확인합니다.

보내주시면 좋은 정보:

- Windows 버전.
- Python 설치 여부.
- 압축 해제 위치.
- 보안 경고 캡처.
- Companion 창 표시 여부.
- 브라우저 자동 열림 여부.
- onboarding 완료 여부.
- 오늘의 신호 3개 생성 여부.
- feedback 클릭 여부.
- 오류 화면 캡처.

브라우저 방문 기록, 로컬 파일 원문, 개인 문서 내용은 보내지 않아도 됩니다.

## C. 설치 문제 발생 시 답장 템플릿

제목: LUMOS 실행 문제 확인을 도와드릴게요

안녕하세요.

실행 문제가 있었다면 아래 항목을 가능한 범위에서 알려주세요. 민감한 개인 데이터는 보내지 않아도 됩니다.

1. Windows 버전: Windows 10 / Windows 11
2. 압축 해제 위치: 예) Downloads, Desktop, 별도 폴더
3. `LUMOS.exe` 실행 시 보인 메시지
4. SmartScreen 또는 Windows Defender 경고가 있었는지
5. Companion 창이 보였는지
6. 브라우저가 열렸는지
7. 가능하면 오류 화면 캡처

브라우저 방문 기록, 로컬 파일 원문, 개인 문서 내용은 보내지 마세요.

## D. 3일 후 follow-up

제목: LUMOS를 다시 열어보셨나요?

안녕하세요.

LUMOS closed beta 사용 후 3일 정도가 지나 짧게 확인드리고 싶습니다.

1. LUMOS를 다시 열어보셨나요?
2. 오늘의 신호가 실제로 유용했나요?
3. 기억에 남는 신호가 있었나요?
4. 불필요하거나 애매했던 신호가 있었나요?
5. 한국어 briefing은 자연스러웠나요?
6. 저장 / 관심 없음 / 계속 추적 버튼의 의미가 명확했나요?
7. 계속 쓰려면 무엇이 먼저 개선되어야 하나요?

짧게 bullet로 답해주셔도 충분합니다.

## E. 7일 후 가격/재사용 의향 follow-up

제목: LUMOS를 계속 쓸 이유가 있었나요?

안녕하세요.

일주일 사용 기준으로 LUMOS의 재사용 의향과 가격 가설을 확인하고 싶습니다.

1. 앞으로도 매일 또는 주 2~3회 열어볼 것 같나요?
2. 월 9,900원 Pro에 지불 의향이 있나요?
3. 지불 의향이 있다면 어떤 기능이 반드시 필요할까요?
4. 지불 의향이 없다면 가장 큰 이유는 무엇인가요?
5. 현재 쓰는 대체 도구와 비교하면 어떤 점이 낫거나 부족했나요?
6. 개인정보/local-first 설명은 충분히 신뢰됐나요?
7. 다른 사람에게 추천할 가능성이 있나요?

가능하면 15분 인터뷰로 더 자세히 듣고 싶습니다.
