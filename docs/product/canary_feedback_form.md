# Canary Feedback Form

Canary tester 1명이 첫 실행 후 보내줄 답변 양식이다. 민감한 개인 데이터는 적지 않는다.

## A. 환경

1. Windows 버전은 무엇인가요?
2. Python이 설치되어 있나요?
3. zip 파일을 어디에 압축 해제했나요?
4. 사용 중인 보안 프로그램이 있나요? 예: Windows Defender, 회사 보안 프로그램, 별도 antivirus
5. 인터넷 연결 상태는 안정적이었나요?

## B. 실행

1. zip 압축 해제는 성공했나요?
2. `LUMOS.exe`를 실행할 수 있었나요?
3. Windows SmartScreen 경고가 보였나요?
4. Windows Defender 또는 antivirus 경고가 보였나요?
5. firewall 허용 창이 보였나요?
6. `LUMOS Companion` 창이 보였나요?
7. 브라우저가 자동으로 열렸나요?
8. 브라우저가 열리지 않았다면 `http://127.0.0.1:8000/app` 직접 접속은 됐나요?

## C. 첫 사용

1. 첫 화면이 무엇을 하라는 뜻인지 이해됐나요?
2. `시작하기` 버튼을 바로 찾을 수 있었나요?
3. onboarding을 끝까지 완료했나요?
4. 오늘의 신호 3개가 생성됐나요?
5. signal card 내용이 이해됐나요?
6. details를 열어봤나요?
7. 저장 / 관심 없음 / 계속 추적 중 하나를 눌러봤나요?
8. 버튼 의미가 명확했나요?

## D. 문제

1. 막힌 지점이 있었나요?
2. 오류 메시지가 있었나요?
3. 오류 화면이나 보안 경고 화면 캡처가 있나요?
4. 앱을 닫고 다시 실행했을 때 정상 동작했나요?
5. Companion 창이나 Web UI에서 글자가 잘리거나 깨진 곳이 있었나요?

## E. 가치와 가격

1. 이 제품이 무엇을 해주는지 이해됐나요?
2. 계속 써보고 싶은가요?
3. 월 9,900원 Pro에 대해 어떻게 느끼나요?
4. 돈을 내려면 어떤 기능이 반드시 필요할까요?
5. local-first 개인정보 설명은 충분히 신뢰됐나요?
6. 다른 사람에게 추천할 가능성이 있나요?
