# Pricing Validation Plan

Date: 2026-07-06

## Price Hypothesis

Primary hypothesis:

- Pro: 9,900 KRW per month
- Free: 0 KRW
- Team: future pricing

This is a validation hypothesis, not an active paid product.

## Initial Personas

- aspiring founder / PM
- solo builder
- AI productivity tool user
- startup and technology trend watcher
- knowledge worker who reads English source material often

## Free / Pro / Team Boundary Hypothesis

Free:

- 3 daily signals
- basic sources
- local mode
- short history
- limited context connector policy later

Pro:

- more daily signals
- automatic briefing
- advanced sources
- expanded context connectors
- longer history
- priority processing candidate

Team:

- team workspace
- shared briefing
- member management
- team billing
- admin settings

## 9,900 KRW Validation Questions

- Would you pay 9,900 KRW per month if LUMOS saved 20 minutes per day?
- What signal quality would make the price acceptable?
- How many useful signals per week would justify payment?
- Which source or connector would make Pro compelling?
- Would you pay more for reliable Korean briefing of English source material?
- What would make this feel like another newsletter rather than a product?

## Landing CTA Metrics

- beta CTA click rate
- pricing page view rate
- Pro card CTA click rate
- download page view rate
- product preview click rate
- manual beta contact count

## Beta Conversion Targets

Early target:

- 5-10 meaningful beta conversations
- 30% of interviewed users can explain LUMOS in one sentence
- 20% express willingness to test weekly
- 10% express conditional willingness to pay

## Pro Conversion Criteria

Pro is promising if users say:

- it saves recurring research time
- Korean briefing is more useful than raw links
- feedback controls make recommendations feel personal
- 9,900 KRW feels acceptable for weekly use

## Lower Price Signals

- users value it only as a casual newsletter
- signal quality is inconsistent
- Korean briefing feels generic
- users want it only once per week
- source coverage is too narrow

## Higher Price Signals

- users rely on it for work decisions
- teams want shared briefing
- Pro users request more connectors
- startup/PM users use it daily
- source monitoring saves measurable time

## Team Expansion Signals

- users forward cards to teammates
- teams ask for shared briefing history
- managers want common source policy
- teams ask for billing/admin controls
