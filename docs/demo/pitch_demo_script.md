# Pitch Demo Script

Date: 2026-06-30

## 30-Second Version

```text
요즘은 정보가 부족한 게 아니라 너무 많아서 고르는 시간이 문제입니다.

LUMOS는 사용자의 관심사와 최근 맥락을 바탕으로 오늘 봐야 할 신호만 골라주는 개인 브리핑 앱입니다. Hacker News, GitHub, RSS 같은 영어 원문 자료도 먼저 한국어 브리핑으로 보여주고, 원문은 자세히 보기에서 확인할 수 있습니다.

사용자는 신호를 저장하거나, 관심 없다고 하거나, 계속 추적하도록 피드백할 수 있고, 이 반응이 다음 추천에 반영됩니다. 현재 Companion은 정식 앱 전 단계의 로컬 실행 도우미이고, 최종적으로는 조용히 도착하는 데스크톱 브리핑 경험으로 확장할 수 있습니다.
```

## 1-Minute Version

```text
LUMOS의 문제의식은 간단합니다. 정보가 부족한 것이 아니라, 너무 많아서 매일 무엇을 봐야 할지 고르는 시간이 든다는 점입니다.

그래서 LUMOS는 뉴스를 많이 보여주는 앱이 아니라, 사용자의 관심사와 최근 맥락을 바탕으로 오늘 볼 만한 신호를 줄여주는 앱입니다.

처음에는 역할과 관심 키워드만 입력합니다. 예를 들어 예비 창업자나 PM이 AI agent, 생산성 툴, 스타트업에 관심이 있다고 알려주면, LUMOS는 Hacker News, GitHub, RSS 같은 소스에서 관련 흐름을 확인하고 한국어 브리핑 카드로 정리합니다.

카드에는 왜 중요한지, 왜 나에게 추천됐는지, 다음에 무엇을 보면 좋은지가 나옵니다. 영어 원문 제목과 snippet은 자세히 보기 안에 보존하고, 원문 보기도 바로 연결합니다.

사용자가 저장, 관심 없음, 계속 추적 같은 피드백을 주면 다음 추천 기준에 반영됩니다. 현재 Companion은 로컬 실행 도우미이고, 최종적으로는 백그라운드에서 조용히 도착하는 데스크톱 브리핑 경험으로 확장할 수 있습니다.
```

## 3-Minute Version

```text
LUMOS는 정보 탐색 피로를 줄이기 위한 로컬 개인 브리핑 MVP입니다.

우리가 매일 겪는 문제는 정보가 없는 것이 아닙니다. Hacker News, GitHub, 공식 블로그, 뉴스레터, RSS처럼 볼 곳은 너무 많습니다. 문제는 이 중에서 오늘 나에게 의미 있는 변화가 무엇인지 고르는 데 시간이 든다는 점입니다.

LUMOS는 이 문제를 "더 많이 보여주기"가 아니라 "덜 보여주기"로 풀려고 합니다. 사용자의 관심사와 최근 맥락을 기준으로 오늘 봐야 할 신호만 골라서 한국어로 정리합니다.

처음 실행하면 Companion이 열립니다. Companion은 메인 앱이 아니라 로컬 실행 도우미입니다. 실제로 읽고 설정하는 화면은 브라우저의 Web UI입니다.

처음 사용자는 시작하기를 누르고, 어떤 일을 하는지와 요즘 보고 싶은 주제를 입력합니다. 예를 들어 예비 창업자 / PM이고, AI agent, 생산성 툴, 스타트업에 관심이 있다고 입력합니다. 기본 설정은 오늘의 신호 3개로 되어 있어서 설정을 많이 만지지 않아도 바로 첫 브리핑을 받을 수 있습니다.

오늘의 신호를 받으면 카드가 만들어집니다. 중요한 점은 원문이 영어여도 기본 카드는 한국어 브리핑이라는 점입니다. 제목, 요약, 왜 중요한가, 왜 나에게 추천됐나요, 다음에 볼 것이 한국어로 먼저 보입니다. 원문 제목과 snippet은 숨기지 않고 자세히 보기 안에 보관합니다.

사용자는 각 신호에 저장, 관심 없음, 계속 추적 같은 반응을 줄 수 있습니다. 이 피드백은 다음 추천에 반영됩니다. 즉 LUMOS는 단순히 자료 목록을 보여주는 앱이 아니라, 사용자의 반응을 통해 점점 더 맞는 신호를 고르는 방향으로 가는 앱입니다.

현재는 로컬 MVP라서 로그인, 결제, 정식 설치 앱은 없습니다. 하지만 핵심 경험은 검증할 수 있습니다. 사용자가 검색하지 않아도 오늘 봐야 할 신호가 조용히 도착하고, 영어 원문 기반 자료도 한국어로 이해할 수 있게 해주는 경험입니다.
```

## Required Messages

- 정보가 부족한 것이 아니라, 너무 많아서 고르는 시간이 문제다.
- LUMOS는 사용자의 관심사와 최근 맥락을 바탕으로 오늘 봐야 할 신호를 골라준다.
- 영어 원문 자료도 한국어 브리핑으로 바꿔 보여준다.
- 사용자는 저장, 관심 없음, 계속 추적으로 피드백할 수 있다.
- 피드백은 다음 추천에 반영된다.
- Companion은 정식 앱 전 단계의 로컬 실행 도우미다.
- 최종적으로 조용히 도착하는 데스크톱 브리핑 경험으로 확장할 수 있다.

## Avoid

- AI가 알아서 다 해줍니다.
- 완벽한 자동화입니다.
- 모든 정보를 수집합니다.
- 실시간으로 모든 트렌드를 추적합니다.
- 상용 서비스가 이미 준비됐습니다.
