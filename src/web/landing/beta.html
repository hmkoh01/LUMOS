Before applying

신청 전 확인해 주세요.

로컬 우선

브라우저 기록과 로컬 파일 원문은 기본적으로 서버로 보내지 않는 방향입니다. connector는 사용자가 켠 경우에만 사용합니다.

Windows 우선

첫 beta build는 Windows portable 형태를 우선 검증합니다. macOS와 정식 installer는 이후 단계입니다.

아직 상용 출시 전

실제 결제, 회원가입, 일반 공개 다운로드는 아직 없습니다. 베타는 제품 가치와 사용성을 확인하기 위한 단계입니다.

보안 경고 가능성

현재 alpha portable build는 code signing 전 단계라 SmartScreen 또는 antivirus 경고가 보일 수 있습니다. 신뢰할 수 있는 전달 경로로 받은 파일만 실행하세요.
