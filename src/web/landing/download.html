Download readiness

Windows portable alpha build를 canary tester 1명 기준으로 먼저 확인하고 있어요.

LUMOS는 아직 일반 공개 다운로드 단계가 아닙니다. Cohort 1 전체 발송 전에 신뢰 가능한 canary tester 1명에게만 zip 형태의 Windows portable build를 수동 전달하는 흐름을 점검 중입니다.

이 페이지에서는 실제 다운로드 파일을 제공하지 않습니다. installer, code signing, auto-update는 다음 배포 단계에서 검토합니다.

현재 준비 중인 build

  • Windows 10/11 대상 portable zip
  • Python 설치 없이 실행하는 `LUMOS.exe`
  • LUMOS Companion 실행
  • 브라우저에서 `/app` 자동 열림
  • First-run onboarding과 오늘의 신호 생성
  • Cloud backend 없이 local mode 사용

아직 제공하지 않는 것

  • 정식 installer
  • code signing
  • auto-update
  • OS startup 또는 tray 실행
  • 회원가입, 결제, 요금제 관리
  • 일반 공개 다운로드

베타 사용자 안내

선정된 beta tester에게는 실행 방법, 개인정보 안내, 알려진 한계, 피드백 가이드를 함께 전달합니다.

현재 alpha portable build는 code signing 전 단계라 Windows SmartScreen, antivirus, firewall 경고가 보일 수 있습니다.
